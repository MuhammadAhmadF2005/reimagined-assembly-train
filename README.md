# Assembly Workspace

This repository contains digital logic design labs and projects organized by folder. It appears to be used for coursework involving Verilog simulations, FPGA design, and related tasks.

## Structure

- `coal-labs/` – Collection of Verilog testbenches and waveforms.
- `DLD project/` – Arduino sketches and other project code.
- `DLD stuff/` – Project files from Quartus or similar tools.
- `Project Backups/` – Autosaved project backups.

Each subfolder often contains testbenches (`*_tb.v`, `.vvp`, `.vcd`) and source Verilog files.

## Usage

1. Open the desired lab or project folder in an appropriate IDE (Quartus, ModelSim, etc.).
2. Compile and simulate the Verilog files using your toolchain.
3. Reference the provided testbenches for correct functionality.

> **Note:** This README is a generic overview; please consult your course instructions for specific details.
